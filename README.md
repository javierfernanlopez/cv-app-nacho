Sistema integral de preparación, generación y seguimiento de candidaturas personalizadas para **Ignacio Fernández López**, adaptado específicamente para el sector de **Consultoría Inmobiliaria, Valoraciones, Asesoramiento Financiero (Deals/Real Estate) y Promoción Inmobiliaria** en **Málaga, Costa del Sol y Andalucía**.

> **Optimizado para Correo Web**: Diseñado para que Ignacio pueda enviar todas las solicitudes directamente desde su navegador (Gmail Web, Outlook Web, etc.) sin depender de un Mac ni de clientes de correo de escritorio.

## 🚀 Inicio Rápido

### Iniciar la Aplicación Interactiva
```bash
npm start
```
Luego abre tu navegador en **`http://localhost:3001`** (o `http://localhost:3000`).

Desde el dashboard podrás:
- **Navegar por las 22 empresas analizadas** con filtros de prioridad y canal.
- **Acceso en 1 clic a Correo Web**:
  - `🚀 Enviar (Gmail Web)`: Abre directamente la ventana de redacción en Gmail Web (`ignflopez@gmail.com`) con destinatario, asunto y texto ya rellenados, descargando simultáneamente el CV en PDF A4 de 1 página listo para adjuntar.
  - `✉️ Outlook Web`: Abre el redactor de Outlook.com / Office 365 Web.
  - `📋 Copiar Todo`: Copia asunto y mensaje al portapapeles en 1 clic.
- **Alternar roles y previsualizar en tiempo real**: Cambia el rol estratégico o activa/desactiva la fotografía según el tipo de canal.
- **Exportar en PDF de 1 página A4**: Cada empresa tiene su PDF ya compilado y listo en `dist/`.
- **Tracker de Candidaturas**: Guarda el estado (*Pendiente, Enviado, En Proceso, Entrevista*) en el navegador.

## ✉️ Instrucciones de Envío para Ignacio (Correo Web)

1. **Empresas con Email Directo (12 empresas)**:
   - Haz clic en **`🚀 Enviar (Gmail Web)`** o **`✉️ Outlook Web`**.
   - Se descargará automáticamente tu **CV en PDF de 1 página**.
   - Se abrirá una nueva pestaña con tu correo web, con la dirección de la empresa, el asunto profesional y el cuerpo del mensaje ya redactados.
   - Solo tienes que arrastrar el archivo PDF descargado a la ventana del correo y hacer clic en **Enviar**.

2. **Empresas con Portal Web (10 empresas)**:
   - Haz clic en **`🌐 Ir al Portal Web`** y en **`📥 Descargar PDF`**.
   - Haz clic en **`📋 Copiar Mensaje`** para pegar el texto de presentación si el formulario dispone de un campo de carta de motivación.
